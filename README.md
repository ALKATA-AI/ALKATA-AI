Our work focuses on exploring innovative approaches, developing intelligent algorithms, and translating research ideas into practical implementations.

## 🚀 Featured Projects

### GSE-Net
**Multi-Scale Feature Extraction for Single-Channel Speech Enhancement**

An official implementation of a deep learning architecture combining convolutional neural networks and Transformer-based attention mechanisms for single-channel speech enhancement.

- Paper: [IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/11710484)
- Source Code: [GitHub Repository](https://github.com/ALKATA-AI/GSE-Net)
- Paper & Resources: [Papers with Code](https://paperswithcode.co/paper/131884)

**Technologies:** Python · PyTorch · CNN · Transformers · Attention Mechanisms
